Arquivos:
- index.html: página principal, one-page.
- sobre.html: página institucional.
- privacidade.html: política de privacidade.
- termos.html: termos de uso.
- style.css: identidade visual.
- assets/: imagens fornecidas pelo cliente.

Como publicar:
1. Envie todos os arquivos mantendo a estrutura de pastas.
2. O index.html deve ficar na raiz do domínio.
3. Bootstrap e Bootstrap Icons são carregados por CDN.
4. Antes de campanhas, confirme horários, serviços, direitos/licenças das imagens e configure eventuais tags do Google Ads/Analytics conforme o que realmente for utilizado.
